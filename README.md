## Hi, I'm yostealthcore! 👋

Most of what I build starts with a small question I can't let go of, like the pathfinding visualizer I'm writing in Python to watch Dijkstra and A* explore a grid step by step. I care a lot about data structures and algorithms, mainly because I like knowing why one approach beats another rather than just that it does, and I keep a few Java and C++ projects around to feel how differently the same idea behaves. Outside of coursework you'll usually find me in a Linux terminal, tuning dotfiles or tinkering with a hobby project that started as a throwaway script.
